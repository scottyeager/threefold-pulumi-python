This deployment creates a cluster of VMs that all share the same specs and the same network. It also creates an Ansible inventory for the deployed VMs.

Depending on the value of `IP_TYPE`, the inventory will include an `ansible_host` of either the public IPv6 address of the VM or its WireGuard address. Each entry will also include a `service_host` value that is always set to the WireGuard IP.

## Prometheus

After deploying your cluster, you can install Prometheus and its Node Exporter using the included Ansible playbook. This is designed for a setup where each node runs its own Prometheus instance and performs a remote write to an external instance that collects all the cluster's metrics.

Before running the playbook, edit the `inventory.ini` file that was generated by the Pulumi script under the `ansible` folder. Write in your Prometheus URL, username, and password.

Now you can execute the playbook:

```
cd ansible
ansible-playbook -i inventory.ini deploy_prometheus.yaml
```

### Adding scrape targets

The Prometheus config template includes a `scrape_config_files` parameter set to `/etc/prometheus/scrape_configs/*.yaml`. This means that you can add scrape targets by dropping `.yaml` files into that folder, rather than editing the base config. This is especially useful for playbooks designed to operate on clusters deployed by this script.
